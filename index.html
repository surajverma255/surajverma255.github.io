AI · RAG · LLM Evaluation · Python
Ask the Stripe Docs — RAG Assistant

A production-deployed retrieval-augmented generation assistant that answers developer questions from Stripe's documentation, cites the exact pages it used, and declines when the docs don't cover a question. Ingests 114 pages via Stripe's llms.txt index, splits them into 2,425 passages with structure-aware chunking and heading breadcrumbs, embeds them with BGE (ONNX via fastembed) into ChromaDB, and generates grounded answers with gpt-oss-120b on Groq. Every answer ships with its evidence: retrieved passages, similarity scores and citations. Evaluated end to end with retrieval metrics and an independent LLM-as-judge for faithfulness; live on Render.
